# Contributing to eSim Tool Manager

Thanks for your interest in contributing to eSim Tool Manager.

## Development Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Running Tests

Before opening a pull request, make sure the test suite passes:

```bash
pytest
```

## Pull Request Guidelines

- Keep changes focused on a single feature or bug fix.
- Follow the existing project structure and coding style.
- Add or update tests when modifying functionality.
- Ensure all tests pass before submitting a pull request.
- Update documentation if your changes affect user-facing behavior.

Thank you for contributing!
